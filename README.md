# 💪 FitZone - Fitness Website

A responsive fitness website built with **HTML and CSS**. It showcases workout programs, trainers, membership plans and a contact/join section to help visitors start their fitness journey.

🔗 **Live Demo:** https://santhosh452j.github.io/fitness-website/

---

## 📸 Screenshots

> Add your screenshots to an `images` folder and update the paths below.

![Home Page](images/screenshot-home.png)

---

## ✨ Features

- Responsive layout that works on mobile, tablet and desktop
- Navigation bar with smooth links to every section
- Hero section with a call-to-action button
- Workout programs section (Strength, Cardio, Yoga, etc.)
- Meet-the-trainers section
- Membership pricing plans
- BMI or benefits section
- Contact / join-now form
- Clean footer with contact details and social links
- Hover effects using pure CSS

## 🚀 How to Run the Project

1. **Clone the repository**
   ```
   git clone https://github.com/santhosh452j/fitness-website.git
   ```
2. **Open the folder**
   ```
   cd fitness-website
   ```
3. **Open `index.html`** in any browser (double-click it, or use the *Live Server* extension in VS Code).

No installation or internet connection is required.

---

## 🎨 Customization

- **Change colors:** edit the CSS variables at the top of `style.css`.
- **Change images:** replace the files in the `images` folder and keep the same file names.
- **Change text:** edit the content directly in `index.html`.
